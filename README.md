# 5-Minute Meditation Timer

> A calm, single-file **5-minute meditation timer** web app — no build step, no dependencies, no sign-up. Open it in any browser and start meditating.

---

## Features

- **5-minute countdown timer** with a clear, large display
- **Start / pause / reset** controls
- **Visual progress** showing elapsed and remaining time
- **Ambient, distraction-free design** — calming colors, clean typography
- **Completion sound cue** (Web Audio API — no external audio files needed)
- **Zero dependencies** — pure HTML, CSS, and JavaScript in one file
- **Fully offline** — works without an internet connection once loaded
- **Mobile-friendly** responsive layout

## Tech Stack

- **HTML5** — page structure
- **CSS3** — styling and animations (no frameworks)
- **Vanilla JavaScript** — timer logic and audio cue

No build tools, no npm packages, no backend.

## Quick Start

1. Clone or download this repository:
   ```bash
   git clone https://github.com/girishlade111/5-Minute-Meditation-Timer.git
   ```
2. Open `index.html` in any modern browser.
3. Press **Start** and begin your 5-minute meditation session.

That's it — no installation, no server, no login.

## Usage Tips

- Use **pause** when interrupted and **reset** to start a session over.
- Keep the tab open — the timer runs entirely in your browser.
- For the best experience, pair it with a quiet room and headphones.

## Deployment

Static site hosted on **GitHub Pages** directly from this repository's `main` branch — no build step required. Any static host (Cloudflare Pages, Netlify, Vercel) can serve it as-is.
